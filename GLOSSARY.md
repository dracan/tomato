# Tomato

A desktop Pomodoro timer: you work in timed focus sessions separated by breaks, and it keeps a history of what you worked on.

## Language

### Sessions

**Focus Session**:
A timed stretch of work on a single Goal, lasting its Estimate.
_Avoid_: Pomodoro (for a single session), timebox, task session

**Estimate**:
The length you choose for a Focus Session: how long you expect its Goal to take, in whole minutes. 25 unless you choose otherwise.
_Avoid_: Custom duration, target, timebox length

**Overtime**:
The time spent on a Focus Session after its Estimate has run out, while you are still working towards its Goal. It is optional and off unless you turn it on.
_Avoid_: Overrun, extra time

**Time Spent**:
How long a Focus Session actually ran, from start to when it ended, not counting pauses. It can be shorter than the Estimate (finished early) or longer (Overtime).
_Avoid_: Actual, duration, elapsed

**Short Break**:
A rest between Focus Sessions within a Cycle.

**Long Break**:
The longer rest taken once a Cycle is complete.

**Cycle**:
Four completed Focus Sessions, ended by a Long Break.
_Avoid_: Set, round

### Outcomes

**Goal**:
What you intend to get done in a Focus Session, written down when it starts.
_Avoid_: Task, objective

**Results**:
What you actually got done in a Focus Session, written down when it ends, with an optional 1-5 star rating.
_Avoid_: Feedback, outcome
